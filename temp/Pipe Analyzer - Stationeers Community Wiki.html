Pipe Analyser
Properties
Stacks Yes (5)
Recipe
Created With Hydraulic Pipe Bender
Cost 20g Iron, 2g Gold, 2g Copper, 2g Electrum
Logic
Item Hash 435685051
Item Name StructurePipeAnalysizer
  • v
  • t
  • e


Description

Just like the Pipe Meter it can be used to display the pressure inside the pipes, but also displaying the contents and temperature. It requires 5W of power and can be hooked up to consoles or computers.
